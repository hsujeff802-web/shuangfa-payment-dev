# 雙發付款管理系統 V8.3 DEV Build 001・5.6 智慧語音安全版

本版以 V8.1・5.6 亮色優化版為基礎，保留既有 localStorage 資料鍵，更新後不會主動清除原付款資料。

## 初次登入

- 登入代碼：`admin`
- 登入密碼：`1234`

登入後請到「系統設定 → 登入與密碼」修改初始密碼。

## 本版完成

- 登入代碼與密碼（密碼雜湊保存）
- 登入錯誤 5 次暫時鎖定
- 閒置 30 分鐘自動登出
- 已付款資料鎖定，不再直接修改原始內容
- 管理員可新增修改紀錄，永久保留修改前、修改後、原因、記錄人與時間
- 首頁新增「修改紀錄」入口
- 中文智慧語音與提示音：
  - 輸入錯誤
  - 付款儲存完成
  - 修改紀錄完成
  - 完整備份完成
  - 開啟系統自動備份完成
  - 支票今天到期、明天到期或已逾期
- 語音可分項開關，並可調整音量及速度
- 編輯廠商基本資料時，不再回頭改動舊付款紀錄

## iPhone／iPad 注意事項

iOS 通常需要先點一下畫面才允許播放聲音。開啟系統後的自動備份及到期語音，會在第一次操作時播放。

## 建議測試

1. 使用 `admin / 1234` 登入。
2. 到系統設定測試「資料已備份完成」語音。
3. 故意漏填付款欄位，確認錯誤語音。
4. 儲存一筆付款，確認付款完成語音。
5. 在付款明細按「新增修改紀錄」，確認原始資料完全不變。
6. 從首頁「修改紀錄」查看更正歷程。

部署時請將 ZIP 內全部檔案一起上傳。
